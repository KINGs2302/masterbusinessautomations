# Master Business Automations

Simple, Apple-inspired translucent (frosted glass) static website for **Master Business Automations** (*E2E Project & Supply*).

## Features

- Apple-style translucent frosted-glass UI (`backdrop-filter: blur(...) saturate(...)`) with light and dark glass appearance toggle
- Responsive layout across desktop and mobile
- Verified GST registration & leadership profile section (`24AAKFE0699M1ZY`)
- One-click copy for GSTIN, office address, and project inquiry summary

## Files

- `index.html` — Semantic page structure
- `styles.css` — Apple transparent glassmorphism styling and theme tokens
- `script.js` — Theme toggle, mobile navigation, clipboard helpers, and scroll reveal

## Local Preview

Open `index.html` directly in any modern browser, or serve the folder locally:

```bash
python -m http.server 8080
```
